# FSR→LED (2026-10-22)
회로: 5V → FSR 402 → A0 → 10kΩ → GND / LED + 220Ω → 3번(~PWM), GND 공통

## 실측 (1부)
- 안 누름 0, 최대 988, 살짝 닿음 300~600
- 누를수록 LED가 밝아지는 회로 성공
- 시뮬(최대 466)보다 범위가 훨씬 넓다 → `map()` 입력 범위는 실측값(0~988)으로 정한다

## 코드에서 알게 된 것 (코치 설명)
- `A0`는 Arduino 코어가 정의한 상수(Nano에서 14). 디지털 핀은 숫자 그대로 쓴다(Nano AVR 코어에는 `D3`라는 이름이 없음).
- `const int`는 초기화 뒤 바꿀 수 없는 정수. 실수로 대입하면 컴파일 오류가 나고, 컴파일러가 값으로 바꿔 넣어 SRAM을 쓰지 않을 수 있다.
- `constrain(x, a, b)`는 x를 a~b 범위로 자른다. v가 988을 넘으면 `map` 결과가 255를 넘는데(1023 → 264), `analogWrite`는 8비트라 264가 8이 되어 갑자기 어두워진다 → 이것을 막는다. 매크로라서 괄호 안에 함수 호출을 넣지 않는다.

## 문제
- 실험 중 USB 연결이 자주 끊김. 의심: 5V·GND 점퍼가 서로 닿는 순간 PC의 USB 과전류 보호가 동작, 또는 케이블·포트 접촉 불량.
