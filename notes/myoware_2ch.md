# MyoWare 2채널 동시 관찰 (2026-11-04)
스케치: [sketches/myoware_2ch/myoware_2ch.ino](../sketches/myoware_2ch/myoware_2ch.ino) (A0 = MyoWare(1) 굴곡근, A1 = MyoWare(2) 신전근, 115200, 약 100Hz, 채널 전환 후 첫 값 버림)
전원: 노트북 배터리, 벽 전원 기기 분리 / 두 보드 VIN→Nano 5V, GND 공통 / 점퍼는 팔꿈치 쪽으로

| 동작 (3초×3) | Set 1 flex | Set 1 ext | Set 2 flex | Set 2 ext |
|---|---|---|---|---|
| 쉼 | 20~22 | 23~25 | 19~21 | 21~23 |
| 손목 굽힘 | 50~120 / 50~110 / 50~110 | 20대 후반 / 20대 후반 / 30대 | 최대 500 / 300 / 250 | 50대 / 30대 / 30대 |
| 손목 젖힘 | 40대 / 30대 / 20대 후반 | 80~140 / 80~180 / 80~140 | 40대 / 30대 / 40대 | 최대 350 / 400 / 300 |
| 주먹 | 60~110 / 50~100 / 60~120 | 50~100 / 40~90 / 50~90 | 180 / 140 / 210 | 140 / 120 / 140 |

- 굽힘에는 A0, 젖힘에는 A1만 크게 오름 → 두 채널 분리 잘 됨(Set 2 기준 반대 채널은 쉼보다 10~30 정도만 오름)
- 주먹 쥐기는 두 채널이 함께 오름(동시 수축)
- 포화(1023) 없음, 쉼 노이즈 ±1~2
- Set 2가 Set 1보다 진폭이 2~3배 큼, 반복할수록 최대값이 줄어듦
