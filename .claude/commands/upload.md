TacLinkArm 저장소의 변경 사항을 정리해 GitHub에 올린다. CLAUDE.md 규칙을 따른다. 사용자 메모: $ARGUMENTS

1. `git pull --rebase`로 최신화. 충돌이면 멈추고 알린다.
2. `git status`와 `git diff --stat`로 변경·새 파일을 모두 나열한다.
3. CLAUDE.md '커밋 전 점검' 1~4를 수행한다. 고친 곳은 목록으로 남긴다.
4. 아래 중 하나라도 있으면 **커밋하지 말고** 목록을 보여 주고 확인을 받는다: 삭제·이름 변경, 10MB 초과 파일, 영상, 비밀정보 의심, 폴더 규칙에 안 맞는 위치, README 소개문·기획서 변경.
5. 없으면 논리 단위로 나눠 커밋하고 `git push`.
6. `git log origin/main --oneline -5`로 원격 반영을 확인한다.
7. 마지막에 아래 형식으로 짧게 보고한다(사용자가 일일 코치에게 그대로 붙여 넣을 수 있게):

```
[TLA 업로드 YYYY-MM-DD]
- 커밋: <해시> <메시지> (여러 개면 줄마다)
- 올린 것: <파일·폴더 요약>
- 고친 것: <마크다운 수정 등, 없으면 없음>
- 확인 필요: <보류한 항목, 없으면 없음>
```
